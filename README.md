# DP Visualizer - 动态规划可视化工具

这是一个用于可视化01背包问题及其变体的交互式工具。

## 功能特性

- **基础01背包（二维）**：展示二维DP表格的填充过程
- **基础01背包（一维）**：展示一维DP空间优化的过程
- **目标和**：展示目标和问题的DP解法
- **分割等和子集**：展示分割等和子集问题的DP解法
- **最后一块石头的重量II**：展示最后一块石头问题的DP解法
- **一和零**：展示二维容量背包问题的DP解法

## 使用方法

1. 打开 `dp2-01.html` 文件
2. 选择不同的标签页查看不同的问题
3. 输入参数后点击"初始化"按钮
4. 点击"下一步"按钮逐步查看DP表格的填充过程
